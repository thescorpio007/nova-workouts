# Nova Workouts

Daily tai chi sessions, other workouts with times, meals, water and weekly weight, with a weight goal, BMI and progress curve.

- Data stays on the phone; password-protected backups go to **Download/NovaWorkouts**.
- Water and workout reminders, times set in the app.
- Updates itself from this repo's GitHub Releases (daily check + manual button, signed SHA-256 checksums, one tap to install).

Built automatically by GitHub Actions on every push to `main`. Each release is tested on an emulator first.
